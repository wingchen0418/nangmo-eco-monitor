科普实验 · 一粒鱼粮的富营养化之旅

上届课题组的对照实验：过量鱼粮投入水体后，土壤浸出液检测显示——这正是我们预警引擎"EC 扰动→排查投喂"规则的实验依据。

极端鱼粮对照组检测结果

过量投喂组的水-土系统出现典型的富营养化指纹：氨氮飙升至常规水体的数百倍，磷钾同步累积。pH 暂未漂移，说明系统缓冲尚未崩溃——但一旦崩溃就是藻华。
